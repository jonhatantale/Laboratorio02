# Reflexión del laboratorio

1. ¿Qué diferencia existe entre un commit normal y un amend?
El commit normal es un nuevo registro dentro del repositorio, y el ammend permite modificar el ultimo commit.

2. ¿Cuándo se produjo el fast-forward?
Se produjo en la parte 5, donde se combino la rama feature/perfil en main.

3. ¿Para qué sirve la opción --no-ff?
Obliga a GitHub a hacer un merge commit no importando si podría ser una combinación directa.

4. ¿Qué significa que exista un conflicto?
Ocurre cuando Git no puede combinar cambios automáticamente o si existe conflicto con archivos al hacer commits.

5. ¿Cómo se resolvió el conflicto de config.txt?
Se resolvió abriendo el archivo txt, eliminando manualmente la causa del conflicto y reemplazandolo por el valor deseado.

El entender cómo funciona la terminal y las funciones aplicadas.
